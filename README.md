# Compasso do Fôlego (app instalável)

Guia visual e sonoro de técnicas de respiração, em formato PWA: instala na tela inicial do Android e funciona sem internet depois da primeira abertura.

## Publicar

Hospede esta pasta em qualquer endereço **https** (GitHub Pages, Netlify, Vercel). Não precisa de build.

## Instalar no Android (Chrome ou Samsung Internet)

1. Abra o endereço no celular.
2. Toque em **Instalar** no aviso do app, ou no menu ⋮ → **Instalar app** / **Adicionar à tela inicial**.

## Atualizar

Ao trocar arquivos, mude `VERSION` em `sw.js` para o app instalado baixar a versão nova.
